# Arktur в Google Play — пошаговая инструкция

Игра уже устроена как устанавливаемое веб-приложение (PWA). Google Play принимает такие приложения в «обёртке»
**Trusted Web Activity (TWA)**: в магазине это обычное приложение, а внутри открывается сайт игры — без адресной строки, на весь экран.
Переписывать игру не нужно. Платить нужно только один раз — **25 $ за аккаунт разработчика**.

Что лежит в этой папке:

| Файл | Зачем |
|---|---|
| `listing-ru.md`, `listing-en.md` | тексты для страницы в магазине: название, краткое и полное описание |
| `store/feature-graphic.png` | баннер 1024×500 для страницы приложения |
| `store/icon-512.png` | значок 512×512 |
| `store/screens-en/`, `store/screens-ru/` | снимки экрана телефона 1080×1920 |
| `assetlinks.example.json` | образец файла, который связывает приложение с сайтом |

Значок и снимки перегенерировать: `python3 tools/make-store-art.py` и `node tools/make-store-shots.js`.

## 1. Сайт с игрой

Сначала игра должна работать по адресу `https://…` — например, на GitHub Pages (содержимое `dist/arktur-site.zip`).

**Важно про адрес.** Файл-подтверждение `assetlinks.json` должен лежать в **корне** домена: `https://ДОМЕН/.well-known/assetlinks.json`.
У GitHub Pages два варианта:
- репозиторий называется **`ВАШ-НИК.github.io`** — тогда игра открывается по адресу `https://ВАШ-НИК.github.io/`, и всё просто;
- репозиторий называется иначе (например, `arktur`) — игра будет по адресу `https://ВАШ-НИК.github.io/arktur/`. Тогда создайте **второй**
  репозиторий `ВАШ-НИК.github.io` и положите в него только папку `.well-known` с файлом `assetlinks.json` и пустой файл `.nojekyll`.

## 2. Пакет для Android — через PWABuilder (без программ на компьютере)

1. Откройте **https://www.pwabuilder.com**, вставьте адрес игры и нажмите **Start**. Сайт проверит манифест, значки и офлайн-режим — у Arktur всё это есть.
2. **Package For Stores → Android → Generate Package.** В настройках:
   - **Package ID** — например `io.github.ваш_ник.arktur` (только латиница, точки; поменять потом нельзя);
   - **App name** — `Arktur`, **Launcher name** — `Arktur`;
   - **Display mode** — `Fullscreen`; **Signing key** — `Create new`.
3. Скачайте архив. В нём:
   - `*.aab` — файл для загрузки в Google Play;
   - `*.apk` — можно поставить на свой телефон для проверки;
   - `signing.keystore` и `signing-key-info.txt` — **ключ подписи. Сохраните их в надёжном месте (не в публичный репозиторий!)** — без них нельзя выпускать обновления;
   - `assetlinks.json` — файл подтверждения сайта.
4. Положите `assetlinks.json` на сайт по адресу `https://ДОМЕН/.well-known/assetlinks.json`
   (если собираете сайт сами: скопируйте файл в `publish/google-play/assetlinks.json` — `node tools/build-public.js` положит его в `.well-known/` автоматически).

> Альтернатива для опытных: утилита Google **Bubblewrap** (`npm i -g @bubblewrap/cli`, затем `bubblewrap init --manifest https://ДОМЕН/manifest.webmanifest`). Нужны Java и Android SDK.

## 3. Аккаунт разработчика

1. **https://play.google.com/console** → регистрация, взнос **25 $** (один раз), подтверждение личности.
2. По правилам Google (на момент подготовки инструкции) **новый личный аккаунт** перед публикацией для всех должен пройти
   **закрытое тестирование: не меньше 12 тестировщиков в течение 14 дней подряд**. Позовите друзей: им нужен аккаунт Google и ссылка на тест.
   Точные условия смотрите в самой консоли — Google их иногда меняет.

## 4. Приложение в консоли

1. **Создать приложение**: название `Arktur`, язык по умолчанию — русский (английский добавите как перевод), тип — **Игра**, **Бесплатное**.
2. **Страница в магазине** — тексты из `listing-ru.md` и `listing-en.md`, значок, баннер и снимки из папки `store/`.
   Категория — **Симуляторы** (или Стратегии).
3. **Политика конфиденциальности** — ссылка `https://ДОМЕН/privacy.html` (уже есть в сборке).
4. **Безопасность данных** — «Приложение не собирает и не передаёт данные пользователей» (игра правда ничего не отправляет: сохранения на устройстве).
5. **Возрастной рейтинг** — анкета IARC: насилие — «фэнтезийное/научно-фантастическое, без крови» (бой кораблей в космосе), азартных игр нет,
   общения с незнакомцами нет (в публичной версии чата с другими людьми нет), покупок нет. Обычно получается 7+ / 12+.
6. **Целевая аудитория** — 13+ (не «дети», иначе действуют особые правила).
7. **Реклама** — «Нет».

## 5. Выпуск

1. **Тестирование → Закрытое тестирование → Создать выпуск** → загрузите `.aab`.
2. В **Настройки → Целостность приложения → Подпись приложений** скопируйте **SHA-256 сертификата ключа подписи приложения** (это ключ Google)
   и **добавьте** его вторым отпечатком в `assetlinks.json` на сайте (образец — `assetlinks.example.json`).
   Без этого приложение из магазина будет показывать сверху строку с адресом сайта.
3. Добавьте тестировщиков, дождитесь 14 дней — и подайте заявку на выпуск в **Рабочую версию**.

## 6. Обновления

Игра в приложении — это ваш сайт. **Новая версия игры = новый архив на GitHub Pages**: игроки получат её при следующем запуске.
Новый `.aab` в Google Play нужен только если меняются название, значок или Package ID.
