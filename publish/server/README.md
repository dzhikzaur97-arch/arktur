# Онлайн-сервер Arktur: общий мир для друзей

Одиночная версия (сайт на GitHub Pages и приложение) запускает вселенную прямо в браузере игрока. Чтобы друзья летали **в одном мире**
— видели друг друга, торговали на одной бирже, воевали в одной войне фракций, — нужен сервер. Код для этого уже есть: `server/index.js`
(та же симуляция, связь по WebSocket, сохранение в один файл `db.json`, пароли хранятся только в виде хеша scrypt).

GitHub Pages для этого не подходит: он отдаёт только файлы и не умеет запускать программы. Нужен хостинг с Node.js.
Ниже — три варианта, от простого к дешёвому. Цены — ориентировочные, на момент подготовки инструкции.

## Вариант 1. Render.com (проще всего, около 7 $ в месяц)

1. Зарегистрируйтесь на https://render.com через GitHub.
2. **New → Blueprint** → выберите репозиторий с игрой. Render прочитает файл `render.yaml`: соберёт сервер по `Dockerfile` и подключит диск
   на 1 ГБ для сохранений.
3. Через пару минут игра будет доступна по адресу вида `https://arktur.onrender.com`. Этот адрес и отправьте друзьям.

Бесплатный тариф Render засыпает без игроков и не сохраняет файлы между перезапусками — пилоты пропадут. Поэтому в `render.yaml` указан тариф Starter с диском.

## Вариант 2. Fly.io (около 3–5 $ в месяц)

```
fly launch --no-deploy        # приложение по fly.toml
fly volumes create arktur_data --size 1
fly deploy
```
Адрес будет вида `https://arktur.fly.dev`.

## Вариант 3. Свой VPS (от 4–5 $ в месяц)

На любом сервере с Docker:
```
docker build -t arktur .
docker run -d --restart=always -p 80:8080 -v arktur-data:/data --name arktur arktur
```
Без Docker: установите Node.js 20, затем `npm ci --omit=dev && PORT=8080 node server/index.js`.
Для HTTPS поставьте перед игрой Caddy или nginx: сайт по HTTPS и WebSocket (`wss://`) нужны для установки как приложения.

## Что важно знать

- **Резервные копии.** Весь мир — один файл `/data/db.json` (рядом — `db.json.bak`). Скачивайте его время от времени.
- **Нагрузка.** Сервер рассчитан на небольшую компанию: десяток-другой игроков на самом простом тарифе.
- **Защита от читов.** Все решения принимает сервер: деньги, урон, награды. Клиент только присылает команды; лишние запросы отбрасываются.
- **Функции claude.ai** (живые NPC, помощник) на своём сервере не работают — они доступны только в версии на claude.ai.
- **Язык.** Игроки переключают русский и английский на экране входа.
