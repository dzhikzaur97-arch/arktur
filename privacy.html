Политика конфиденциальности ARKTUR: Космический рубеж

  • Игра бесплатная. В ней нет рекламы, покупок, аналитики и сторонних трекеров, и сама игра не собирает и не отправляет данные.
  • Прогресс, настройки и сохранения хранятся в хранилище браузера на вашем устройстве. Их можно выгрузить в файл и загрузить обратно в меню «Сохранения».
  • Имя пилота и пароль, которые вы вводите в игре, нужны только чтобы разделять пилотов на этом устройстве, и игрой никуда не передаются.
  • Сайт игры размещён на GitHub Pages. GitHub, как любой хостинг, может записывать технические данные запросов (например, IP-адрес) по своей политике конфиденциальности.
  • Кнопка «Отправить на GitHub» в окне «Сообщить о проблеме» открывает страницу отзывов игры на GitHub с текстом отчёта (модель устройства и видеокарты, последние ошибки игры, имя пилота и место в игре). Отправлять ли его, решаете вы; отправленный отзыв виден всем, а GitHub обрабатывает данные по своей политике конфиденциальности.
  • Игру создали Salamov Rustam и Claude — ИИ-ассистент компании Anthropic, с помощью которого написан код игры. Эта версия игры к Claude и другим ИИ-сервисам не подключается.

Privacy policy — ARKTUR: Space Frontier

  • The game is free. It has no ads, purchases, analytics or third-party trackers, and the game itself collects and sends no data.
  • Progress, settings and saves are stored in your browser storage on your device. You can export them to a file and import them back in the Saves menu.
  • The pilot name and password you enter in the game only separate pilots on this device and are not sent anywhere by the game.
  • The game website is hosted on GitHub Pages. Like any host, GitHub may log technical request data (such as IP addresses) under its own privacy policy.
  • The «Send to GitHub» button in the «Report a problem» window opens the game feedback page on GitHub with the report text (device and GPU model, recent game errors, pilot name and in-game location). Whether to submit it is up to you; submitted feedback is public, and GitHub processes data under its own privacy policy.
  • The game was made by Salamov Rustam together with Claude, Anthropic's AI assistant, which helped write the game's code. This version of the game does not connect to Claude or any other AI service.
