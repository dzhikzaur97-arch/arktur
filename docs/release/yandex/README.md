# Яндекс Игры — ARKTUR: Космический рубеж (alpha 0.82.1)

Архив для загрузки: `dist/release/arktur-0.82.1-yandex.zip` (собирается `node tools/build-release.js`;
в GitHub — релизом, см. [../RELEASE.md](../RELEASE.md)). `index.html` и все ресурсы — в корне архива, относительные пути,
24 файла, ≈3,4 МБ в архиве / 7,1 МБ распакованно. Контрольная сумма — в `dist/release/SHA256SUMS.txt`.

## Что делает сборка для Яндекса
- Подключает `<script src="/sdk.js">` — **только в этой сборке**. Игра не стартует, пока не ответит `YaGames.init()`:
  язык берётся из `ysdk.environment.i18n.lang` **до** того, как игра выбирает язык (ru/be/uk/kk/uz → русский, иначе — английский;
  выбор игрока в настройках потом сохраняется).
- Если `YaGames.init()` отвечает дольше 10 с — экран «Подключаемся к Яндекс Играм…» с кнопкой «Повторить», **но ожидание
  продолжается**: поздний успешный ответ SDK запускает игру. Если `/sdk.js` не загрузился — сообщение и «Повторить».
  Запуск без SDK — только по явному тестовому флагу `?vfLocalTest=1` (для локальной проверки, в черновике не нужен).
- `ysdk.features.LoadingAPI.ready()` — один раз, когда загружены модели кораблей и экран входа готов к вводу.
- `GameplayAPI.start()` — когда пилот в игре и нет паузы; `stop()` — меню Esc, пауза платформы, вкладка без фокуса, выход.
- `game_api_pause` / `game_api_resume`, `blur` / `focus`, скрытие вкладки: симуляция останавливается, Web Audio
  (`AudioContext.suspend()`) и озвучка реплик (`speechSynthesis.pause()`) замолкают, новые реплики не начинаются.
  Снятие паузы платформой **не снимает** ручную паузу игрока (меню Esc). Звук, включённый впервые во время паузы
  (вход в игру на паузе), создаётся сразу приостановленным. Настройки игрока (громкость, «Озвучка») не меняются.
- Без свободного чата (только сообщения игры), без своей кнопки «Во весь экран», без внешних ссылок, без Claude/ИИ-запросов,
  без рекламы и покупок, без входа в аккаунт Яндекса.
- Политика конфиденциальности — **внутри игры**: ссылка на экране входа и кнопка «Помощь → Об игре → Политика конфиденциальности»
  (русский/английский по языку игры); тот же текст — `privacy.html` в архиве и [../privacy/yandex.html](../privacy/yandex.html).
  Текст честно перечисляет, что уходит платформе через SDK (готовность, разметка геймплея) и что Яндекс обрабатывает данные
  и статистику по своим правилам; он не обещает «никаких данных и аналитики».
- CSP: скрипты — свои и с доменов Яндекса (`yandex.ru/com/net`, `yastatic.net` и национальные зоны), соединения/фреймы/картинки
  SDK — по https, `object-src 'none'`, `base-uri 'self'`.

## Как загрузить (делает владелец аккаунта)
1. Консоль разработчика Яндекс Игр → новое приложение → загрузить `arktur-0.82.1-yandex.zip`.
2. Языки: русский и английский. Название: **ARKTUR: Космический рубеж** / **ARKTUR: Space Frontier**.
   Описания, управление, категории — в общем пакете публикации (`docs/release/`), скриншоты 16:9 — в материалах.
3. Монетизация: **не включать** (ни рекламы, ни покупок). В поле **«Комментарий разработчика»** (вкладка «Черновик»)
   вставить текст ниже — это разрешённое исключение из требования 1.12
   (https://yandex.com/dev/games/doc/en/requirements/1/12).
4. Политика конфиденциальности: если консоль просит адрес — разместить `docs/release/privacy/yandex.html` на своём сайте
   (например, GitHub Pages) и указать его; внутри игры политика уже есть.

## Что проверено, а что — только в размещённом черновике
Проверено локально (Chromium, имитация SDK, `tools`-тесты в описании ветки):
- поздний ответ SDK (14 с) запускает игру; при отсутствии ответа и при пустом `/sdk.js` игра не стартует сама, есть «Повторить»;
- `YaGames.init()` вызывается до выбора языка; ru/en/tr → ru/en/en; `LoadingAPI.ready()` — один раз и после загрузки;
- пауза платформы и blur: симуляция стоит, AudioContext `suspended`, речь на паузе, новые реплики не начинаются;
  `resume` возвращает звук и речь и не снимает меню Esc; первая инициализация звука на паузе — сразу `suspended`;
- `GameplayAPI` размечает каждую паузу и возврат; сохранение переживает перезагрузку; нет запросов наружу и 404;
- окно политики открывается на экране входа и из «Помощи», на языке игры.

**Не проверено (можно только после регистрации, в черновике на Яндексе)** — проверьте и отметьте:
- [ ] настоящий SDK грузится без ошибок CSP в консоли браузера (в том числе стартовая реклама платформы, если она будет);
- [ ] отладочная панель черновика видит `LoadingAPI.ready` и разметку `GameplayAPI`;
- [ ] стартовая реклама/оверлей платформы приходит как `game_api_pause` → игра и звук на паузе, после `game_api_resume` — продолжение;
- [ ] переключение языка черновика (ru/en) меняет язык игры при первом запуске;
- [ ] переключение вкладок и сворачивание окна ставят паузу; сохранения переживают перезагрузку в черновике.
