Политика конфиденциальности ARKTUR: Космический рубеж

  • Игра бесплатная. Сама игра не показывает рекламу и не продаёт покупки. Платформа Яндекс Игры может показывать собственный контент, в том числе рекламу при запуске, по своим правилам.
  • Игра работает на платформе Яндекс Игры и подключает Yandex Games SDK. Через SDK игра сообщает платформе: что игра загрузилась и готова (LoadingAPI.ready); когда игровой процесс идёт и когда остановлен — пауза, меню, сворачивание вкладки (GameplayAPI start/stop). Из SDK игра получает язык интерфейса и сигналы паузы платформы.
  • Яндекс как платформа собирает и обрабатывает данные — например, технические данные устройства и браузера, IP-адрес, статистику запусков и времени в игре — по своим правилам и политике конфиденциальности. Разработчик игры может видеть в консоли Яндекс Игр обобщённую статистику игры, которую формирует платформа.
  • Игра не запрашивает вход в аккаунт Яндекса, не использует облачные сохранения Яндекса и не передаёт свои сохранения ни Яндексу, ни разработчику.
  • Прогресс, настройки и сохранения хранятся в хранилище браузера на вашем устройстве. Их можно выгрузить в файл и загрузить обратно в меню «Сохранения».
  • Имя пилота и пароль, которые вы вводите в игре, нужны только чтобы разделять пилотов на этом устройстве, и игрой никуда не передаются.
  • Вопросы о данных платформы — к Яндексу; вопросы об игре — через страницу игры на Яндекс Играх.
  • Игру создали Salamov Rustam и Claude — ИИ-ассистент компании Anthropic, с помощью которого написан код игры. Эта версия игры к Claude и другим ИИ-сервисам не подключается.

Privacy policy — ARKTUR: Space Frontier

  • The game is free. The game itself shows no ads and sells nothing. The Yandex Games platform may show its own content, including an ad at launch, under its own rules.
  • The game runs on Yandex Games and includes the Yandex Games SDK. Through the SDK the game tells the platform: that it has loaded and is ready (LoadingAPI.ready); when gameplay is running and when it is stopped — pause, menu, tab hidden (GameplayAPI start/stop). From the SDK the game receives the interface language and the platform pause signals.
  • As a platform, Yandex collects and processes data — such as technical device and browser data, IP address, launch and play-time statistics — under its own rules and privacy policy. The game developer may see aggregated game statistics produced by the platform in the Yandex Games console.
  • The game does not ask for a Yandex login, does not use Yandex cloud saves and does not send its saves to Yandex or to the developer.
  • Progress, settings and saves are stored in your browser storage on your device. You can export them to a file and import them back in the Saves menu.
  • The pilot name and password you enter in the game only separate pilots on this device and are not sent anywhere by the game.
  • Questions about platform data — to Yandex; questions about the game — via the game page on Yandex Games.
  • The game was made by Salamov Rustam together with Claude, Anthropic's AI assistant, which helped write the game's code. This version of the game does not connect to Claude or any other AI service.
