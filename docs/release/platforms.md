# Публикация по площадкам — что загружать и что заполнить

Все архивы собираются `node tools/build-release.js` → `dist/release/` (лимиты проверяются автоматически,
отчёт — `dist/release/MANIFEST.json`, суммы — `SHA256SUMS.txt`). Постоянные ссылки — GitHub Release, см. [RELEASE.md](RELEASE.md).
Тексты страниц — [listing.md](listing.md), политики конфиденциальности — [privacy/](privacy/), материалы — [media/](media/).
Аккаунты, договоры, налоги и выплаты оформляет владелец; здесь их нет.

| Площадка | Файл | Что внутри сборки |
|---|---|---|
| itch.io (играть в браузере) | `arktur-<версия>-itch-html5.zip` | index.html в корне, относительные пути, без сервера и сети; язык — по браузеру; без свободного чата |
| itch.io (скачать) | `arktur-<версия>-itch-download.zip` | один `ARKTUR.html` со всем внутри — открывается двойным щелчком, без интернета |
| CrazyGames (Basic Launch) | `arktur-<версия>-crazygames.zip` | без SDK, рекламы и входа; английский по умолчанию; без своей кнопки «Во весь экран», внешних ссылок и свободного чата; пауза и тишина без фокуса |
| Poki (первая заявка) | `arktur-<версия>-poki.zip` | как CrazyGames; Poki SDK **не подключён** |
| Яндекс Игры | `arktur-<версия>-yandex.zip` | см. [yandex/README.md](yandex/README.md) |
| Windows (itch / Steam / сайт) | `ARKTUR-Setup-<версия>-x64.exe`, `ARKTUR-<версия>-win-x64.zip` | Electron 45, офлайн, без подписи |

## itch.io
1. Новый проект → Kind of project: **HTML** → загрузить `itch-html5.zip`, отметить **«This file will be played in the browser»**.
2. Размер окна: 1280 × 720, включить **Fullscreen button** и **Mobile friendly** (ориентация — любая).
3. Дополнительно загрузить `itch-download.zip` (Windows/macOS/Linux — это HTML-файл) и Windows-сборку
   `ARKTUR-<версия>-win-x64.zip` с пометкой Windows.
4. Pricing: **No payments** (или «$0 or donate» — по желанию владельца). Release status: **In development** / Alpha.
5. Раздел о генеративном ИИ: отметить, что ИИ использовался; текст — «Об использовании ИИ» из listing.md.
6. Лимиты: каждый файл ≤ 7 МБ (index.html ≈ 5,5 МБ), 24 файла — проверено сборкой.

## CrazyGames — Basic Launch
- Загрузить `crazygames.zip` (≈ 3,5 МБ, 24 файла; лимиты ≤ 50 МБ и ≤ 1500 файлов проверены сборкой).
- Без SDK, без рекламы, без внешнего входа. Язык по умолчанию — английский (русский — в настройках игры).
- Обложки: 1920×1080, 800×1200, 800×800; видео: landscape 1920×1080 и portrait 1080×1620, 15–20 с, без звука и курсора,
  первый кадр — соответствующая обложка (см. media/).
- Если игру примут на Full Launch, понадобится интеграция CrazyGames SDK — в этой сборке её нет.

## Poki — первая заявка
- Для заявки: публичная ссылка на игру (например, страница itch.io или сайт на GitHub Pages) и 3 игровых скриншота ≤ 5 МиБ
  (media/poki-*.jpg).
- `poki.zip` — английская сборка без свободного чата для их проверки. **Poki SDK не подключён и не имитируется**:
  интеграция SDK, их требования и договор — только после того, как Poki примет игру.

## Steam — черновик страницы (без AppID, без банковских и налоговых данных)
- Тип: игра; статус: **Ранний доступ / Coming soon** (альфа). Цена — решает владелец (сейчас игра бесплатна на других площадках).
- Название: ARKTUR: Space Frontier / ARKTUR: Космический рубеж. Описания — listing.md.
- Жанры/теги: Space, Sandbox, Simulation, Singleplayer, Exploration, Mining, Trading, Sci-fi. **Не указывать** MMO, Multiplayer, Co-op, PvP.
- Возможности: Single-player. Нет: Steam Achievements, Steam Cloud, Trading Cards, контроллер (не проверялся) — не отмечать.
- Языки: интерфейс и тексты — English, Russian; озвучки нет.
- Системные требования (минимум): Windows 10 x64, 4 ГБ ОЗУ, видеокарта с WebGL 2 / DirectX 11, 400 МБ на диске.
- Сборка: Windows-приложение из релиза (`win-unpacked` из electron-builder или ZIP). **Steamworks SDK не интегрирован** —
  достижения/облако Steam нет; если нужно — отдельная задача.
- Опрос о содержимом ИИ (Content Survey): **Pre-generated** — да: код игры и игровые тексты написаны с помощью ИИ-ассистента
  Claude (Anthropic) под руководством автора; **Live-generated** — нет: игра не генерирует контент ИИ во время игры.
- Материалы: капсулы и скриншоты — из media/ (Steam требует свои размеры капсул — 460×215, 616×353, 231×87, 1232×706 и др.;
  их можно вырезать из обложек media/, текстов на скриншотах быть не должно).
- Юридические данные разработчика, налоговые формы, банковские реквизиты, взнос Steam Direct — заполняет владелец в Steamworks.

## Windows (сайт / itch / Steam)
- Установщик `ARKTUR-Setup-<версия>-x64.exe` (выбор папки, ярлыки) и portable `ARKTUR-<версия>-win-x64.zip` (распаковать и запустить ARKTUR.exe).
- Без цифровой подписи: Windows SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».
  Подпись требует сертификата разработчика — это решение владельца.
- Сохранения: `%APPDATA%\ARKTUR`. Сеть не используется.
